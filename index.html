Programming Language · C · 2022–Present
Pilang

A lightweight programming language for machine learning, numerical computing, data processing, and visualisation. Combines Python-like readability with JavaScript-like flexibility, small enough to embed directly into applications. Built around a bytecode VM written in C with native support for tensors, plotting, statistics, and OOP - data-oriented programming is a first-class concern, not an afterthought.

  • Native tensor operations, statistics, 3D visualisation, and ML workflows - no external ecosystem required
  • Bytecode VM with computed-goto dispatch and call-site inline caches for fast execution
  • Syntax inspired by Python and JavaScript: comprehensions, closures, classes, operator overloading, ranges, slices, tuples
  • Targets scientific computing, simulation, education, and interactive data exploration
  • Standard library: math, io, fs, tensor, canvas, net, stats, random, plot

Scripting Language · Games & Graphics
Pi-Script

A lightweight scripting language and SDL runtime for building small games, graphics experiments, and interactive tools. Runs inside a virtual-console-style 128×128 framebuffer environment while still letting projects load normal media files alongside their scripts.
